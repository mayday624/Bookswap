# 1. PRODUCT SUMMARY
BookSwap is a mobile-first web app (installable PWA) where people exchange books they have finished reading. Users list books they are willing to give away, add a wishlist of books they want, get matched with nearby people, chat, agree on a meeting place, and swap in person. Later milestones add communities, textbook/set-book support, WhatsApp sharing, phone verification, referrals, and reading streaks. The target users are communities in Kenya (e.g., Narok, Nairobi), mostly on Android phones with slow or limited data, so the app must be lightweight and fast.

# 2. TECH STACK
- Frontend: React + Vite + TypeScript, Tailwind CSS, React Router. Lazy load routes. No heavy libraries.
- Backend: Supabase (Postgres, Auth, Storage, Realtime). Row Level Security on every table.
- PWA: manifest, service worker, installable, offline-friendly shell, small bundle size.
- Book data: Open Library API (ISBN and title search, covers), with fallback to manual entry.
- ISBN scanning: browser BarcodeDetector API where available, fallback library (e.g., html5-qrcode), and always a manual ISBN/title entry option.
- Location: browser Geolocation API plus manual selection of town/area. Store only approximate coordinates (rounded to ~1 km) and a text area name. Never expose exact addresses.
- Environment variables for all keys. Provide .env.example and a clear README (create Supabase project, run migrations, set env vars, run locally, deploy to Vercel or Netlify).

# 3. CORE FEATURES (Milestones 1-8)

## Auth and profile
- Sign up / log in with email + password and Google sign-in.
- Profile: display name, avatar, short bio, town/area, favorite genres. Edit profile, log out, delete account.

## Books (listings)
- Add a book: scan ISBN or search by title, auto-fill title, author, cover, description.
- Fields: condition (Like new / Good / Fair / Worn), genre, language, optional personal note, up to 3 photos.
- Status: Available, Reserved, Swapped. Edit and delete own listings.
- "My Shelf" page showing my books by status.

## Wishlist
- Add wanted books (title/author/ISBN, optional genre-only wishes like "any thriller"). Edit and remove items.

## Discover and search
- Home feed of available books near me, sorted by distance.
- Search by title/author; filter by genre, condition, language, and distance (5 km, 20 km, 50 km, anywhere).
- Book detail page: cover, details, condition photos, owner summary and rating, approximate distance, "Request swap" button.

## Matching
- "Matches for you" page:
  1. Perfect match: another user has a book on my wishlist AND wants a book I have.
  2. One-way match: someone nearby has a book on my wishlist.
- Notification (in-app, optional browser push) when a new book matching my wishlist is listed nearby.

## Swap flow
- Request a swap: choose one of my available books to offer, or use a credit.
- Owner can accept, decline, or counter-offer.
- When accepted, both books become Reserved and a chat opens.
- Both users propose and confirm a meeting place and time in the chat.
- After meeting, both tap "Confirm swap completed". When both confirm, books become Swapped and each can rate the other.
- Either user can cancel before completion, which releases the books back to Available.

## Credit system (solves one-to-one matching)
- Each completed swap where I give a book earns me 1 credit. I can spend 1 credit to request any book from an owner who accepts credit swaps.
- Owners choose per listing: "Swap for a book only" or "Swap for a book or a credit".
- New users start with 0 credits. Show a clear explanation of how credits work. Keep a credit_transactions history table.

## Chat
- Real-time 1-to-1 chat per swap using Supabase Realtime. Text messages, unread counts, timestamps.
- Quick actions in chat: "Suggest meeting place", "Confirm swap completed".
- Never reveal phone numbers or exact locations unless the user chooses to.

## Ratings and trust
- After a completed swap, each user rates the other 1-5 stars with optional comment.
- Show average rating, completed swap count, and a "Trusted swapper" badge after 5+ swaps with rating 4.0 or above.
- "Report a problem" option on swaps (e.g., no-show).

## Safety
- Safety tips screen before the first swap (public places, daytime, tell a friend, inspect the book).
- Suggest public meeting spot types (library, school, cafe, church, market).
- Report and block users; reported users are hidden from the reporter.
- is_admin flag and a simple admin page to review reports and suspend users.

## Notifications
- In-app notification center: new swap request, accepted/declined, new message, wishlist match, swap completed, new rating.

## 9D. Phone number OTP verification
- Use Supabase phone auth with an SMS provider (Africa's Talking or Twilio). Never hardcode keys; use environment variables. Document in the README: enabling the phone provider in Supabase, configuring the SMS provider, expected cost per SMS, and testing with a test number.

- Store the verified phone privately. Never show it publicly or in chat. Public profile exposes only phone_verified (boolean) and timestamp.

- Configurable rules in the config file: unverified users can browse and list books but must verify before requesting a swap, accepting a swap, or using credits. Enforce server-side (RLS or database function), not only in the UI.

## 9E. Referral credits

- Referrals screen under Profile: my code and link, people invited and their status (Signed up / Verified / First swap done), credits earned from referrals, and a clear explanation of how it works.
- In-app notifications: "Your friend {name} joined", "You earned 1 credit, {name} completed their first swap".
- Admin page: top referrers and flagged suspicious patterns (many referrals from the same device or area in a short time).

## 10A. Currently reading and personal streak
- Users can mark any book as "Currently reading" (from a book detail page, My Shelf, or Open Library search). It does NOT need to be a swap listing.
- Fields: book, start date, optional total pages, optional current page, status (Reading / Finished / Paused).
- A "Reading" section on Profile and My Shelf shows current books with a simple progress bar.
- When I mark a book Finished, prompt: "Want to list it for swap?" and prefill the Add Book form. This connects reading to the core swap loop.
- Daily check-in: one tap "I read today" (optionally log pages or minutes).
- Streak counter = consecutive days with a check-in. Show current streak, longest streak, and a 30-day calendar heatmap.
- Rules: use the user's local timezone for day boundaries; 1 "streak freeze" per week so one missed day does not reset the streak; gentle message when a streak is at risk.
- Milestone badges at 3, 7, 30, 100 days, shown on the profile.
- Optional daily reminder (in-app, browser push if allowed). Reminder time is user-configurable and OFF by default.
- UI: streak flame icon with count in the Home top bar; a "Reading" card on the Home feed with today's check-in button, current book, and progress. No heavy animation libraries; a small confetti/flame effect only on milestone badges.

## 10B. Reading buddies (same book)
- On every book detail page, show "X people are reading this book now" (only users who allow it publicly).
- Users can join a Reading Buddies group for a specific book (identified by ISBN or Open Library ID so different editions match).
- Two ways to start: join an open group for that book, or create a group and invite friends or nearby users via a share link.
- Group size 2-10. Groups are "Open" or "Invite only".
- Each group has: member list with each person's progress (page or percent), a shared group streak, and a group chat using the existing Supabase Realtime chat setup.
- Group streak counts consecutive days where at least ONE member checked in (encouraging, not punishing). Show each member's individual streak and a gentle "nudge" button for members who have not read today.
- Spoiler protection: group messages can be tagged with a chapter or page number; messages beyond a member's current progress are hidden until they tap to reveal.
- Weekly group summary notification: who read the most days, group streak status.
- "Find readers nearby reading this book" using the same approximate-location logic (never exact addresses). Suggest an optional in-person meetup for finished groups, reusing the safety tips screen.
- Reading Buddies screen listing my groups and suggested groups.
- Tip for scope: if credits are limited, drop spoiler protection and weekly summaries for version 1.
